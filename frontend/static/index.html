Deterministic Detector Rules Breakdown

severity_spike High (0.95)
Matches HTTP 5xx responses (500–599) or severity in error/critical requiring immediate triage.
burst_frequency High (0.90)
Two-pointer sliding 60-second window flagging ≥10 requests from a single source (DDoS or credential stuffing).
off_hours_access Critical (0.98)
Restricted administrative URI access (/admin, /api/internal, /api/export) during off-hours (00:00 - 06:00 UTC).
rare_event_type Medium (0.75)
Infrequently observed administrative operations occurring ≤1.5% frequency across cluster.
